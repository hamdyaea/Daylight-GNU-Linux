DAYLIGHT / RASPBERRY PI

Give your Pi a different horizon.

Raspberry Pi is at the heart of the project. Add Daylight to 64-bit Raspberry Pi OS: choose the desktop, or just the tools on a headless machine.

DESKTOP

A desktop to explore

Raspberry Pi Connect uses Wayland for screen sharing. Fluxbox runs on X11. On Raspberry Pi, Daylight therefore uses labwc, a lightweight Wayland compositor designed to keep the desktop responsive locally and remotely. Right-click to open the application menu. Conky displays system gauges on the desktop.

Install Daylight Full

CORE

Tools without a desktop

For a headless Pi or a server: keep just the Rust core and local commands. No graphical interface to start.

Choose core mode

Check before installing

The package manager must report arm64. A 64-bit processor may run a 32-bit OS: what matters is the installed system’s architecture.

dpkg --print-architecture
cat /etc/os-release

Target base: Debian 12/13 or compatible Raspberry Pi OS. The native core was tested on Raspberry Pi 4; physical graphical sessions still need validation on each configuration.

After installation

The installer offers a reboot and selects Daylight when the login manager supports it. On Raspberry Pi, the “Daylight GNU/Linux (Wayland)” session uses labwc and supports Raspberry Pi Connect screen sharing. For access immediately after boot, enable desktop autologin and Connect screen sharing. To return to the previous desktop, run sudo daylight remove and reboot. Installation does not add or start a display manager. Raspberry Pi OS Lite needs an appropriate graphical setup; core mode works without a display.
