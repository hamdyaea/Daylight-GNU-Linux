2026-11-08 / APT · 5.0.0~rc4-8

RC4: Shardturn and refreshed interfaces

Shardturn joins the optional games. The other games and tools gain a shared illustrated native interface, with application search, day/night settings, local scores and tournaments.

On an existing Daylight installation, this command updates the installed Daylight packages and their required dependencies. Your settings are preserved.

This is an ARM64 and AMD64 package release. The PC live image remains at 5.0.0-rc.2. A new --all installation includes the optional telemetry package, disabled until explicitly enabled with sudo daylight telemetry on. An update preserves your previous choice.

7 November 2026

Full installation and Debian 13 desktop fixes

APT revision 5.0.0~rc2-5 fixes the Games menu, Fluxbox window movement and resizing, and hides Conky temperature output when no sensor is available.

To update installed Daylight packages:

sudo daylight update

Log out and back in to reload the desktop, or reboot after saving your work. If daylight-games is not installed, add the four extra games with sudo apt install daylight-games.

For a new installation, daylight-install.sh --all --yes installs the desktop, applications and all ten games. Six illustrated games are included in the desktop; daylight-games provides the other four launchers. The installer never installs or activates telemetry. --core remains available for tools only, and --plan previews the selection without installing.

sudo curl -fsSLO https://daylightlinux.ch/daylight-install.sh
sudo sh daylight-install.sh --all --yes

Mouse interactions and Conky loading were tested in an isolated Debian 13 environment. AMD64 and ARM64 packages are published in the signed repository. The ISO image and Web Live demo retain their separate versions.

5 November 2026

Daylight V4’s Conky monitor and six illustrated games return

APT revision 5.0.0~rc2-4 brings together the desktop, game and text-to-speech updates for ARM64 and AMD64.

If Daylight is already installed, open a terminal and run this command to update your installed Daylight packages.

sudo daylight update

Conky brings back V4’s purple CPU graph, paired network graphs and process rankings. The update reloads the Daylight monitor if it is running.

Six illustrated games are included with the desktop. Dice and Coin Flip show the face you rolled or flipped, the slot machine spins its reels, and Memory lets you turn over two cards at a time. Click a picture to play Rock–Paper–Scissors–Lizard–Spock, or advance through the NBA playoffs one round at a time to reveal the champion.

Text to Speech keeps your text on screen during playback. Choose a French, German or English voice and use Speak or Stop. Audio plays on the device running Daylight.
