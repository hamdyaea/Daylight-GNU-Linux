# Daylight Linux website sources

Snapshot of the website deployed at `/var/www/daylightlinux` on a Raspberry Pi.

Maintainer: Hamdy Abou El Anein.

HTML, JavaScript, CSS, site assets, media, translated pages and the text-based live-web interface are included.

Large runtime distributions and generated artifacts are excluded: live VM boot images and WASM binaries, old site snapshots, package repository, source archives, and media source working files. These are not needed to maintain the site's HTML/CSS/JS source.

This folder is a source snapshot, not a complete server or production deployment backup.
