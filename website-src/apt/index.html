Installer sur votre Raspberry Pi

Sur Raspberry Pi OS 64 bits compatible, utilisez --all pour installer le bureau, les applications et tous les jeux. Pour une simulation, remplacez --yes par --plan.

sudo curl -fsSLO https://daylightlinux.ch/daylight-install.sh
sudo sh daylight-install.sh --all --yes

Lire le guide d’installation complet

Le mode --core convient à une machine sans écran. L’installateur n’installe ni n’active la télémétrie. Il présélectionne Daylight lorsque le gestionnaire de connexion le permet et propose un redémarrage.

Official signed APT repository

This repository provides Daylight packages for compatible 64-bit Raspberry Pi OS (ARM64) and Debian (AMD64). Follow the installation guide. The installer previews its plan unless you explicitly use --yes.

The repository is working even when arbitrary subdirectories do not show a file listing. Automatic directory browsing remains disabled intentionally; use the explicit public key, signed metadata and package-index links above. Package managers do not need directory listings.

Daylight 5 is a release candidate. Never bypass signature or expiry checks. No telemetry is enabled by the standard installer.
