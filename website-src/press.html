DAYLIGHT / RASPBERRY PI

Introduce Daylight, simply.

A reusable introduction, the logo and actual screenshots for enthusiasts, user groups and Linux media.

The project in a few lines

Daylight GNU/Linux adds a Fluxbox desktop and Rust tools to 64-bit Raspberry Pi OS. The free-software project by Hamdy Abou El Anein is distributed as Debian packages; an AMD64 PC live image provides a way to explore without installation. The 5.0.0-rc series is a release candidate.

Download the media kit

Facts, not promises

Primary target: 64-bit Raspberry Pi OS. Desktop: Fluxbox and Conky. Tools: Rust and YAD windows. Daylight license: GPLv3. Status: release candidate. Live screenshots come from PC/VM tests and are not presented as Pi benchmarks.

Credits and contact
