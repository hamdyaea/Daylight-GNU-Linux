Become a Daylight GNU/Linux mirror

Help Raspberry Pi and Debian users download Daylight faster and more reliably. Volunteer your HTTPS server as a community APT mirror. Registration is free.

Register your mirror on GitHub

How to join

  1. Prepare a publicly accessible HTTPS server with enough disk space and bandwidth for the signed APT repository.
  2. Read the community mirror setup guide.
  3. Synchronize the official signed repository without modifying its files, and verify that dists/daylight/InRelease is publicly accessible.
  4. Use the registration form above to provide your mirror URL, two-letter country code and optional public name. You can also contact info@daylightlinux.ch.
  5. Once approved, the mirror is monitored. It becomes eligible for public listing after 24 consecutive hours of successful checks.

Community mirror directory

Approved, healthy mirrors are published in the public mirror registry. A community mirror does not replace the official repository automatically.

Mirror registration is independent of optional Daylight telemetry. Never post private credentials or personal contact details in a public GitHub issue.
