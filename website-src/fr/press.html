DAYLIGHT / RASPBERRY PI

Présenter Daylight, simplement.

Une présentation réutilisable, le logo et de vraies captures pour les passionnés, associations et médias Linux.

Le projet en quelques lignes

Daylight GNU/Linux ajoute un bureau Wayland léger avec labwc et des outils Rust à Raspberry Pi OS 64 bits. Le projet libre de Hamdy Abou El Anein se distribue en paquets Debian ; un live PC AMD64 permet de le découvrir sans installation. La série 5.0.0-rc est une version candidate.

Télécharger le kit de présentation

Des faits, pas des promesses

Cible principale : Raspberry Pi OS 64 bits. Bureau : labwc sur Wayland, Fluxbox sur X11 et Conky. Outils : Rust et fenêtres YAD. Licence Daylight : GPLv3. État : version candidate. Les captures live sont réalisées sur PC/VM, pas présentées comme des benchmarks Pi.

Crédits et contact

Conservez les attributions. Le kit ne contient aucune police de caractères. Les licences des images et composants tiers restent distinctes de celle du code.
