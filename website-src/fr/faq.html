DAYLIGHT / RASPBERRY PI

Les réponses avant le premier démarrage.

Compatibilité, installation, suppression et confidentialité : les limites sont aussi importantes que les fonctionnalités.

Raspberry Pi ou PC : quelle version choisir ?

Pour utiliser Daylight sur votre Pi, installez les paquets sur Raspberry Pi OS 64 bits. Le live PC AMD64 est une démonstration pour découvrir le bureau, pas une carte SD pour Raspberry Pi.

Quels systèmes sont pris en charge ?

La version actuelle cible Debian 12/13 et Raspberry Pi OS 64 bits compatible (ARM64). Le cœur a été exécuté sur Raspberry Pi 4. Cela ne certifie pas toutes les combinaisons de modèles, d’écrans et de pilotes. ARM 32 bits n’est pas pris en charge.

Faut-il réinstaller Raspberry Pi OS ?

Non : Daylight ajoute ses paquets à un système compatible existant. Sauvegardez vos données et vérifiez le plan d’installation. Le bureau utilise une session X11 séparée et ne remplace pas automatiquement votre session actuelle.

Comment accéder au bureau après installation ?

À votre prochaine connexion graphique, choisissez « Daylight GNU/Linux » dans le sélecteur de session existant. L’installation n’ajoute ni ne démarre un gestionnaire de connexion. Raspberry Pi OS Lite nécessite une activation graphique adaptée ; le mode core fonctionne sans écran.

Est-ce déjà une version stable ?

Non, la série 5.0.0-rc est une version candidate. Les tests et leurs limites sont publics. Signaler votre matériel et les problèmes rencontrés aide à préparer une version stable, sans inventer de chiffres de performances.

Puis-je le supprimer ?

Oui : daylight remove --dry-run affiche la simulation, puis sudo daylight remove demande la suppression. Quittez d’abord la session Daylight. Aucun autoremove n’est lancé ; dépendances partagées, réglages personnels et configuration APT sont conservés. Ce n’est pas une restauration bit à bit.

Y a-t-il un suivi des utilisateurs ?

Le compteur de démarrages est un paquet distinct, désactivé par défaut. Le script d’installation ne l’active pas. Il compte des événements reçus, pas des utilisateurs uniques. Le site n’ajoute aucun outil analytique publicitaire ; les intermédiaires réseau peuvent voir les connexions.

La démo web utilise-t-elle le Raspberry Pi du projet ?

Non. La démo légère Alpine s’exécute dans votre navigateur avec WebAssembly, sans compte. Le Pi sert uniquement ses fichiers. La démonstration ne nécessite aucun compte et ne lance aucune machine virtuelle sur notre Pi.
