DAYLIGHT / RASPBERRY PI

Essayez Daylight directement sur l’accueil.

Aucun compte, aucune ISO à télécharger : le bureau Linux se lance dans votre navigateur.

Daylight Start

Le bureau graphique se trouve sur la page d’accueil, devant le paysage Daylight. Après avoir cliqué sur Démarrer, patientez quelques minutes pendant le téléchargement et le lancement de Linux. Ce bureau est conçu pour un PC ; certaines fonctions peuvent ne pas marcher sur mobile. Démarrer, Redémarrer et Stop sont les commandes.
