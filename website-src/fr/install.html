DAYLIGHT GNU/LINUX / 5.0.0-rc.2

Installer Daylight au complet.

Recommandé : utilisez --all pour installer le bureau, les applications et tous les jeux. Choisissez --core pour les outils en ligne de commande uniquement. Le script n’installe ni n’active la télémétrie. Sans --yes, il affiche seulement un plan.

1. Télécharger et vérifier

Téléchargez le script, lisez-le, puis affichez son plan. Il n’est pas envoyé directement dans un shell privilégié.

sudo curl -fsSLo daylight-install.sh https://daylightlinux.ch/daylight-install.sh
sh daylight-install.sh --all --plan

2. Choisir le périmètre

Recommandé : --all installe le bureau, les applications et tous les jeux, sans télémétrie. Desktop installe la session graphique et les applications. Core installe uniquement les outils CLI et les fonds d’écran. Sur Raspberry Pi, labwc fournit le bureau Wayland compatible avec le partage d’écran de Raspberry Pi Connect. La session X11 utilise Fluxbox.

Installation complète — recommandée

sudo sh daylight-install.sh --all --yes

Bureau Raspberry Pi

sudo sh daylight-install.sh --desktop --yes

Cœur CLI : serveur ou Pi sans écran

sudo sh daylight-install.sh --core --yes

Confiance dans le dépôt

Le script vérifie cette empreinte complète avant d’accepter le dépôt. Les priorités APT excluent les paquets non-Daylight de cette origine. Aucun trusted=yes ni contournement des signatures.

B0575F821A31DD20753DE07C50D21240F4BCB02E

Public archive key · InRelease · Archive status

3. Garder Daylight à jour

APT vérifie les métadonnées signées et l’intégrité des paquets. La commande Daylight cible les paquets Daylight installés, pas une mise à niveau de la distribution.

daylight update --dry-run
sudo daylight update

Supprimer Daylight

Quittez la session graphique Daylight avant la suppression. Aucun autoremove n’est exécuté ; les dépendances partagées et vos réglages personnels sont conservés.

daylight remove --dry-run
sudo daylight remove

Compatibilité

Systèmes ciblés : Debian 12/13 et Raspberry Pi OS 64 bits compatible. ARM32 et Arch/Manjaro ne sont pas pris en charge par le script. APT peut installer des dépendances ; la désinstallation n’est pas une restauration de snapshot.

Ouvrir la session Daylight

L’installateur propose de redémarrer et présélectionne Daylight lorsque le gestionnaire de connexion le permet. Sur Raspberry Pi, la session « Daylight GNU/Linux (Wayland) » utilise labwc et permet le partage d’écran avec Raspberry Pi Connect. Pour y accéder dès le démarrage, activez la connexion graphique automatique et le partage d’écran de Connect. Pour revenir au bureau précédent, lancez sudo daylight remove puis redémarrez. L’installation n’ajoute ni ne démarre un gestionnaire de connexion. Raspberry Pi OS Lite nécessite une activation graphique adaptée ; le mode core fonctionne sans écran.
