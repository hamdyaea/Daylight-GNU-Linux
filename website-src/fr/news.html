2026-11-09 / APT · 5.0.0~rc4-8

RC4 : Shardturn et nouvelles interfaces

Shardturn rejoint les jeux facultatifs. Les autres jeux et les outils adoptent une interface native illustrée commune, avec recherche d’applications, réglages jour/nuit, scores et tournois locaux.

Sur une installation Daylight existante, cette commande met à jour les paquets Daylight installés et leurs dépendances nécessaires. Vos réglages sont conservés.

daylight update

Cette publication concerne les paquets ARM64 et AMD64. L’image live PC reste en version 5.0.0-rc.2. Une nouvelle installation avec --all inclut le paquet facultatif de télémétrie, désactivé jusqu’à l’activation explicite avec sudo daylight telemetry on. Une mise à jour conserve votre choix précédent.

Historique des révisions RC4

Les numéros ci-dessous correspondent aux révisions des paquets APT, pas aux versions de l’image live PC.

5.0.0~rc4-8 — Déplacement des fenêtres Fluxbox rétabli

Les raccourcis souris de Fluxbox permettent de déplacer les fenêtres par leur barre de titre ou avec Alt + clic gauche et de les redimensionner avec Alt + clic droit. Le correctif est limité à Fluxbox pour ne pas modifier le comportement Wayland du Raspberry Pi.

5.0.0~rc4-7 — Installation de la télémétrie et fiabilité des dépôts

L’interface de confidentialité affiche la commande sudo apt install daylight-telemetry lorsque le paquet facultatif est absent. L’installateur vérifie désormais la liste des trois miroirs APT avant d’activer la source.

5.0.0~rc4-6 — Notifications de mise à jour

Le bureau peut notifier les nouvelles versions des paquets Daylight sans installer automatiquement les mises à jour. La vérification est périodique et évite les notifications répétées pour une même version.

5.0.0~rc4-5 — Miroirs APT et basculement automatique

La configuration APT utilise une liste de trois miroirs : daylightlinux.ch, GitHub Raw et Cloudflare Pages. Les métadonnées restent signées et les miroirs sont synchronisés.

5.0.0~rc4-4 — Télémétrie facultative

Le centre de confidentialité propose le contrôle de la télémétrie, désactivée par défaut. Le paquet facultatif peut être installé sans activer l’envoi de statistiques.

5.0.0~rc4-3 — Corrections des jeux et de l’interface

Les interfaces des jeux ont été retravaillées, notamment les zones d’affichage du Basketball NBA et du Tournament Simulator. Le menu présente Daylight Shardturn.

5.0.0~rc4-2 — Règles historiques des jeux restaurées

Basketball reprend les équipes NBA et la progression des conférences jusqu’au champion. Tournament Simulator reprend la Coupe du monde 2018 ; Coin Flip réutilise les images de pièce existantes.

5.0.0~rc4-1 — Première série de paquets RC4

La série RC4 introduit Shardturn et la modernisation des interfaces des jeux et outils Daylight.

7 novembre 2026

Installation complète et correctifs du bureau Debian 13

La révision APT 5.0.0~rc2-5 corrige le menu Games, le déplacement et le redimensionnement des fenêtres Fluxbox, et masque la température dans Conky lorsqu’aucun capteur n’est disponible.

Pour mettre à jour les paquets Daylight déjà installés :

sudo daylight update

Déconnectez-vous puis reconnectez-vous pour recharger le bureau. Vous pouvez aussi redémarrer après avoir enregistré votre travail. Si daylight-games n’est pas installé, ajoutez les quatre jeux supplémentaires avec sudo apt install daylight-games.

Pour une nouvelle installation, daylight-install.sh --all --yes installe le bureau, les applications et les dix jeux. Les six jeux illustrés sont inclus dans le bureau ; daylight-games fournit les quatre autres lanceurs. Le script n’installe ni n’active la télémétrie. --core reste disponible pour les outils seuls et --plan permet de vérifier le choix sans installer.

sudo curl -fsSLO https://daylightlinux.ch/daylight-install.sh
sudo sh daylight-install.sh --all --yes

Les correctifs souris et le chargement de Conky ont été testés dans un environnement Debian 13 isolé. Les paquets AMD64 et ARM64 sont publiés dans le dépôt signé. L’image ISO et la démo Web Live conservent leurs versions distinctes.

5 novembre 2026

Le Conky de Daylight V4 et les six jeux illustrés sont de retour

La révision APT 5.0.0~rc2-4 réunit les mises à jour du bureau, des jeux et de la synthèse vocale pour ARM64 et AMD64.

Sur une installation Daylight existante, ouvrez un terminal et lancez cette commande pour mettre à jour les paquets Daylight installés.

sudo daylight update

Conky reprend la courbe CPU violette, les deux graphes réseau et le classement des processus de la V4. Si le moniteur Daylight est ouvert, la mise à jour recharge son affichage.

Six jeux illustrés sont inclus avec le bureau. Le dé et la pièce affichent la face tirée, la machine à sous anime ses rouleaux et Memory retourne les cartes par paires. Dans Pierre–feuille–ciseaux–lézard–Spock, vous choisissez votre coup en cliquant sur une image. Le simulateur NBA vous fait avancer tour par tour jusqu’au champion.

La synthèse vocale conserve le texte pendant la lecture. Choisissez une voix française, allemande ou anglaise, puis utilisez Speak ou Stop. Le son sort sur l’appareil qui exécute Daylight.
