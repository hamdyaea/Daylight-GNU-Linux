DAYLIGHT / RASPBERRY PI

Answers before your first boot.

Compatibility, installation, removal and privacy: the boundaries matter as much as the features.

Raspberry Pi or PC: which version?

To use Daylight on your Pi, install the packages on 64-bit Raspberry Pi OS. The AMD64 PC live image is a desktop demonstration, not a Raspberry Pi SD-card image.

Which systems are supported?

The current version targets Debian 12/13 and compatible 64-bit Raspberry Pi OS (ARM64). The core has run on Raspberry Pi 4. That does not certify every board, display and driver combination. 32-bit ARM is not supported.

Must I reinstall Raspberry Pi OS?

No: Daylight adds packages to a compatible existing system. Back up your data and review the installation plan. The desktop uses a separate X11 session and does not automatically replace your current session.

How do I start the installed desktop?

At your next graphical login, select “Daylight GNU/Linux” in the existing session selector. Installation does not add or start a display manager. Raspberry Pi OS Lite needs an appropriate graphical setup; core mode works without a display.

Is this a stable release?

No. The 5.0.0-rc series is a release candidate. Tests and limitations are public. Reporting hardware and problems helps work toward a stable release without inventing performance figures.

Can I remove it?

Yes: daylight remove --dry-run previews removal, then sudo daylight remove requests it. Log out of Daylight first. It never runs autoremove; shared dependencies, personal settings and APT configuration remain. This is not a bit-for-bit restore.

Does it track users?

The boot counter is a separate package, disabled by default. The installer does not enable it. It counts received events, not unique users. The site adds no advertising analytics; network intermediaries can still observe connections.

Does the web demo run on the project’s Raspberry Pi?

No. The lightweight Alpine demo runs inside your browser with WebAssembly, without an account. The Pi only serves its files. The demo requires no account and runs no virtual machine on our Pi.
