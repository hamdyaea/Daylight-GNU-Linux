Before you start

Raspberry Pi or PC: which version?

To use Daylight on your Pi, install the packages on 64-bit Raspberry Pi OS. The AMD64 PC live image is a desktop demonstration, not a Raspberry Pi SD-card image.

Which systems are supported?

The current version targets Debian 12/13 and compatible 64-bit Raspberry Pi OS (ARM64). The core has run on Raspberry Pi 4. That does not certify every board, display and driver combination. 32-bit ARM is not supported.

Must I reinstall Raspberry Pi OS?

No: Daylight adds packages to a compatible existing system. Back up your data and review the installation plan. The desktop uses a separate X11 session and does not automatically replace your current session.
