Login

Keyboard language

dpkg-reconfigure console-data
dpkg-reconfigure keyboard-configuration
service keyboard-setup restart

AMD64 / USB

Flash the image to a USB drive or external disk. If USB boot fails, check UEFI/Legacy boot and Secure Boot settings in your BIOS/UEFI firmware.

Raspberry Pi V4

Use an 8 GB or larger microSD card; 16 GB is safer because some nominal 8 GB cards provide slightly less usable capacity.

sudo fdisk -l
sudo dd bs=1M of=/dev/mmcblk0 if=Daylight-linux-RPI-V4.img status=progress conv=fsync

At first boot run sudo raspi-config, expand the filesystem, then configure locale and keyboard settings.
