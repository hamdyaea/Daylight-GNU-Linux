DAYLIGHT GNU/LINUX / 5.0.0-rc.2

Install without taking over.

The default plan is core-only. Desktop, games and telemetry are independent choices. Nothing in this installer activates telemetry.

1. Download and inspect

Download the script as a file, inspect it, then print its plan. The script is not piped into a privileged shell.

curl -fsSLo install-daylight.sh https://daylightlinux.ch/install.sh
less install-daylight.sh
sh install-daylight.sh --core --plan

2. Choose the scope

Core-only adds the command-line tools and backgrounds. Desktop adds the Fluxbox session and applications; it does not start or replace a display manager.

CLI core: headless Pi or server

sudo sh install-daylight.sh --core --yes

Raspberry Pi desktop

sudo sh install-daylight.sh --desktop --yes

Desktop and optional games

sudo sh install-daylight.sh --desktop --games --yes

Repository trust

3. Keep it current

APT verifies signed metadata and package hashes. Daylight updates request only installed Daylight packages, not a distribution upgrade.

daylight update --dry-run
sudo daylight update

Remove Daylight

Log out of the Daylight desktop before removing it. Removal does not run autoremove; shared dependencies and personal settings are retained.

daylight remove --dry-run
sudo daylight remove

Compatibility

Target systems: Debian 12/13 and compatible 64-bit Raspberry Pi OS. ARM32 and Arch/Manjaro are not supported by the installer. APT may install required dependencies; this is not a snapshot rollback.

Open the Daylight session

At your next graphical login, select “Daylight GNU/Linux” in the existing session selector. Installation does not add or start a display manager. Raspberry Pi OS Lite needs an appropriate graphical setup; core mode works without a display.
