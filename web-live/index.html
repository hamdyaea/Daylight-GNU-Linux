DAYLIGHT START / FLUXBOX / WEBASSEMBLY

Un vrai bureau Linux.
Dans votre navigateur.

Une démo légère et temporaire pour découvrir l’esprit Daylight. Le calcul s’exécute sur votre appareil, pas sur notre Raspberry Pi.

Un aperçu, pas la distribution complète.

Cette édition expérimentale repose sur Alpine Linux x86 et Fluxbox. Daylight pour Raspberry Pi reste basé sur Debian / Raspberry Pi OS ARM64. Cette démo n’inclut pas tous ses outils Rust.

Aucun système n’est lancé avant votre clic. Environ 42 Mo à télécharger. Navigateur récent et ordinateur avec clavier recommandés.

DAYLIGHT WEB

Votre session démarre ici.

Daylight Start ouvre automatiquement le terminal au premier plan. Cliquez dedans pour écrire. Clic droit sur le fond pour les applications, ou Super+Entrée pour un autre terminal. Redémarrer efface la session actuelle ; Stop l’arrête.

Votre session reste locale

Pas de compte, pas de disque partagé avec le serveur, pas de relais réseau pour le système invité et pas de télémétrie. Les fichiers de la démo se téléchargent par HTTPS ; le serveur voit cette connexion comme pour une page web.

Rien à installer

Les changements sont temporaires : fermer, arrêter ou recommencer détruit la session. N’y saisissez pas de mots de passe ou de données sensibles. La démo se met en pause lorsque l’onglet est masqué, reprend à votre retour et se ferme après 20 minutes.

Une démo raisonnable

256 Mio de mémoire sont attribués au Linux invité ; le navigateur utilise aussi sa propre mémoire. Le démarrage dépend de votre appareil et du réseau. Aucun conteneur public ne tourne sur notre Pi.

Détails et licences

Linux est réellement émulé dans WebAssembly avec v86. Il ne s’agit pas d’une capture d’écran interactive. Le réseau externe du système invité est déconnecté. Les bibliothèques et systèmes libres gardent leurs licences.
